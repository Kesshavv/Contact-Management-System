# 📇 Contact Management Dashboard

A modern and visually appealing **Contact Management System UI** built using **HTML, CSS, and JavaScript**.
This project mimics a professional dashboard design with sidebar navigation, contact list, and detailed contact view.

---

## 🚀 Features

✨ Sidebar Navigation (Voicemails, Contacts, Tasks, Settings)
✨ Interactive Contact List
✨ Dynamic Contact Selection
✨ Contact Details Panel
✨ Tabs Section (Voicemails / Tasks / Notes)
✨ Clean & Modern UI Design
✨ Responsive Layout (basic)
